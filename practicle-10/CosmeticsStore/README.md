# Velora Beauty Cosmetics Store

A premium, responsive cosmetics storefront built with HTML5 and CSS3 only.

## Structure
- index.html — Home page
- shop.html — Shop page
- categories.html — Categories page
- about.html — About page
- blog.html — Blog page
- contact.html — Contact page
- offers.html — Offers page
- faq.html — FAQ page
- bestsellers.html — Best Sellers page
- newarrivals.html — New Arrivals page
- css/style.css — Main stylesheet
- css/responsive.css — Responsive media queries

## Preview
Open index.html in your browser to view the site.
